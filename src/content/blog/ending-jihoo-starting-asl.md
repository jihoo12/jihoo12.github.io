---
title: "Ending Jihoo development and starting ASL"
description: "Jihoo is archived, and development has begun on ASL, a separate programming language project."
pubDate: 2026-11-21
---

I've stopped developing Jihoo. I moved the repository to [`jihoo12/jihoo`](https://github.com/jihoo12/jihoo), archived it, and removed the old `jihoolang` organization. The self-hosting compiler and the formal verification work so far remain available in the archive. The full verification goal was not completed.

I've started developing [ASL](https://github.com/jihoo12/asl), a new programming language and a separate project from Jihoo. It's still at an early stage, so for now this is just a note to mark the start.
