Normal desktop apps become objects in a shared 3D world. Windows can move through depth, fold into cubes, collide with the scene, or be picked up and thrown.

- Custom GLES2 renderer and a public C plugin API
- Lua configuration and a standalone desktop shell
- Plugins such as water windows, magnetic windows and portals
